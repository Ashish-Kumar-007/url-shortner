A simple URL shortener for links you can track

Create a compact short link from any HTTP or HTTPS URL. Add an optional expiration time, share the link, and check its click count. This open-source link shortener also provides a straightforward REST API.

Short links with expiration and click statistics

Use short URLs in messages, documents, and campaigns. Each generated link has a unique code, redirects to its original destination, and reports total clicks. Set an expiration when a link should stop working.

URL shortener API

Automate link creation with POST /api/shorten, send visitors through GET /{short_code}, and read click statistics from GET /api/urls/{short_code}/stats. Explore the interactive API docs at /docs.
